# V2 架构决策（Architecture Decision）— v2 修订

日期：2026-10-28（v2 修订）
依据：`V2_OFFICIAL_RULES_EVIDENCE.md` v2（引用 R 编号）
状态：**历史决策记录。最终实施为该文档 §1 的 α 的强化版 α′（单 PIN + 单 PORT，
多个 LAYER/RECT 写在同一 PORT 内），见 `V2_FINAL_INTERFACE_DECISION.md` §1–§3。**

> **读这份文档前请注意**：下文比较的 α 与 β 都停留在"一个 PIN 下有几个 PORT"
> 这一层。实际落地时发现两个 PORT 只构成**弱连通**，router 不保证把同一 PIN
> 下的多个 PORT 当成同一个节点。因此最终实现把全部跨层 RECT 收进**一个**
> PORT —— 强连通由 LEF 直接声明，不依赖 router 的解释。本文档中凡写
> "2 PORT""4 PORT"之处，最终产物都是 1 个 PORT；这是同一个设计意图的更强表达，
> 不是另一个方案。

> **v2 修订说明**：用户指出 v1 的分类判据**是错的**。
> v1 说"所有 PIN 在同一 GDS 分量才允许有端口"——这会让正常的**多 Net 宏**寸步难行。
> 正确的判据是：**同一物理导体上的多个 PIN，必须对应同一逻辑 Net**。
> v1 还错误地断言 C3"必须无端口"。v2 全部更正。

## 0. 修正后的核心问题

### 0.1 真正的矛盾（v1 没抓住）

| 宏 | 物理事实 | 综合网表的 Net | 一致？ |
|---|---|---|---|
| **A** | 两 PIN 在**同一导体**（实测 C0）| `a=pwm_out`, `b=rs_a_out`（**两个 net**）| ❌ **矛盾** |
| **B** | 两 PIN 在**同一导体**（1 分量）| `a=pwm_out`, `b=rs_b_out`（**两个 net**）| ❌ **矛盾** |
| **C1** | 两 PIN 在**同一导体**（1 分量）| `in=pwm_out`, `tap=rs_br_tap`（**两个 net**）| ❌ **矛盾** |
| **C3** | **8 条独立导体** | 8 个 PIN 各接不同 net | ✅ **一致** |
| C4 | 2 条独立导体，无 PIN | 无端口 | ✅ |
| D | 13 个分量，无 PIN | 无端口 | ✅ |
| E | 4 个分量，无 PIN | 无端口 | ✅ |

**结论**：**问题在 A/B/C1，不在 C3。** v1 完全搞反了。

### 0.2 A/B/C1 矛盾的实质

物理：`pwm_out` 和 `rs_a_out` 是**同一个节点**（被 Via1 短接）。
网表：它们是**两个独立 net**。

**后果**（不是 LVS 报不报错的问题，而是网表与物理不自洽）：
- Router 会把它们当两条独立线布线
- 如果各自连到别处，会形成设计者未预期的电气连接
- LVS 若从 GDS 提取宏内部，会报"两个 net 短路"

### 0.3 C3 为什么其实是自洽的

C3 是 8 条独立导体、8 个 PIN、8 个不同 net。**这在技术上完全合法**——
它就是一个 8 端无源器件。

**但这不意味着"必须保留端口"。** 见 §2.3 的科研论证。

## 1. 方案比较：如何表达"一条物理导体，多个接入点"

**这是 A/B/C1 的核心问题。** 三种方案：

### 方案 α：单 PIN + 多 PORT（**推荐**）

```lef
PIN NET
  DIRECTION INOUT ;
  USE SIGNAL ;
  PORT
    LAYER met1 ;
      RECT 0.00 0.00 0.14 0.14 ;     # M1 侧接入点
  END
  PORT
    LAYER met2 ;
      RECT 8.00 2.00 8.14 2.14 ;     # M2 侧接入点
  END
END NET
```

```verilog
(* blackbox *) (* keep *) module research_via1 (inout wire net);
endmodule
```

连接：`research_via1 u_rs_via1 (.net(pwm_out));`

**语义**：这是一个挂在 `pwm_out` 上的**抽头**，可从 M1 或 M2 接入，
两者通过 Via1 内部相连。

**官方依据（REPO_OBSERVATION，强）**：
V1 的顶层 `VGND` 就是**一个 PIN、4 个 PORT**，且通过了官方 Precheck 15/15。

| 维度 | 影响 |
|---|---|
| 综合实例保留 | ✅ `blackbox+keep` 即可（已验证）|
| OpenROAD Pin Access | ⚠️ **UNVERIFIED**：V1 的多 PORT 都在**同一层**（met4），我们的跨 met1/met2 |
| 实际布线 | ✅ Router 选任一 PORT 接入，无冗余 |
| **LVS** | ✅ **一个 PIN、一个 net，不存在"两 net 短路"问题** |
| SEM 跨层几何真值 | ✅ **完全保留**（GDS 几何一字不改）|
| DEF/Netlist 的真实 Net ID | ✅ **保留**（`pwm_out`）|
| 是否需要 Via 承载功能电流 | ✅ 是——这正是研究对象的物理事实 |

### 方案 β：两 PIN + 同一 Net（**备选**）

```verilog
module research_via1 (inout wire a, inout wire b);
endmodule
```
连接：`.a(pwm_out), .b(pwm_out)`（两个端口接同一 net）

| 维度 | 影响 |
|---|---|
| 综合实例保留 | ✅ |
| OpenROAD Pin Access | ✅ 两 PIN 各自独立，风险更低 |
| 实际布线 | ⚠️ Router 会把同一 net 路由到**两个** PIN，冗余（物理上已短路）|
| LVS | ✅ 两 PIN 同 net，内部短路 → 自洽 |
| SEM 几何真值 | ✅ 保留 |
| Net ID | ✅ 保留 |
| Via 承载电流 | ✅ 是 |

**优点**：LEF 完全不用改，只改 `project.v` 一行。
**缺点**：语义上"一个 net 接两个 pin"略绕；路由冗余。

### 方案 γ：两 PIN + 两 Net（**当前状态，错误**）

物理短路，网表两 net。**必须放弃。**

### 1.1 为什么推荐 α 而非 β

| 维度 | α | β |
|---|---|---|
| 语义精确性 | ✅ "一个 net，多个接入点" | ⚠️ "一个 net，两个 pin" |
| 官方先例 | ✅ V1 VGND 四 PORT | ⚠️ 未找到 |
| LEF 改动 | 需要改 | ✅ 不需要 |
| 多 PORT 跨层风险 | ⚠️ UNVERIFIED | ✅ 无 |
| 路由冗余 | ✅ 无 | ⚠️ 有 |

**决策**：**首选 α，β 作为 α 失败时的回退。**
α 的跨层多 PORT 是唯一未验证点，但 LEF 语法允许，且 β 是现成的退路。

## 2. 七个宏的最终模型

### 2.1 A / B / C1 —— 方案 α（单 PIN 多 PORT）

| 宏 | PIN 名 | PORT 位置 | Verilog |
|---|---|---|---|
| A | `net` | met1 @ M1 左端；met2 @ M2 右端 | `inout wire net` |
| B | `net` | met2 @ M2 端；met3 @ M3 端 | `inout wire net` |
| C1 | `net` | met1 @ 主干左端；met2 @ 三个分支端（3 个 PORT）| `inout wire net` |

**C1 特别适合 α**：它本来就是"一个主干 + 三个分支"，用 4 个 PORT
挂在同一个 PIN 上，语义完全准确。

**PIN 名统一为 `net`，与 Verilog 端口名逐字符一致**（修正 R4.3 的大小写问题）。

### 2.2 C3 —— 无端口（**由科研需求决定，不是因为"非法"**）

**先纠正 v1**：C3 的 8 端口**技术上完全合法**（8 个独立导体、8 个 net）。

**那为什么仍推荐无端口？**

| 论点 | 说明 |
|---|---|
| **科研价值不需要 net** | C3 的问题是"SEM 能否区分靠得近与真的相连"。需要的是**几何真值**（8 条线的位置、宽度、间距），不需要"这条线属于哪个信号" |
| **保留端口会破坏几何** | 若 8 个 PIN 接真实信号，router 会布线到它们，**在间距阶梯附近加 via 和走线**，干扰 0.14–0.50 µm 的间距测量 |
| **保持结构纯净** | 无端口 → 无路由 → 8 条线保持设计原样，SEM 图像干净 |
| **负样本真值不丢失** | "8 条互不相连"这个事实由 **GDS 几何**表达，比 net 更直接 |

**这是路线选择，不是合规性问题。** 若将来需要 C3 带 net（例如研究"邻近异 net 串扰"），
完全可以加回 8 个 PIN —— 物理结构不用改。

### 2.3 C4 / D / E —— 保持无端口（不变）

| 宏 | 理由 |
|---|---|
| C4 | 负样本，"不连接"是研究核心；给 net 反而破坏语义 |
| D | 纯几何阶梯，同上（router 会加 via 干扰线宽测量）|
| E | 配准标记，本就不该连任何 net |

### 2.4 决策表

| ID | 结构 | 模型 | PIN | Verilog 端口 | 物理几何 | 真值类型 |
|---|---|---|---|---|---|---|
| A | M1–Via1–M2 | 电气抽头 | `net`（**落地为 1 PORT**，含 2 个 LAYER）| `inout net` | **不改** | GDS + **Net** |
| B | M2–Via2–M3 | 电气抽头 | `net`（**落地为 1 PORT**，含 2 个 LAYER）| `inout net` | **不改** | GDS + **Net** |
| C1 | 单网多分支 | 电气抽头 | `net`（**落地为 1 PORT**，含 4 个 RECT）| `inout net` | **不改** | GDS + **Net** |
| C3 | 邻近独立导体 | 几何宏 | **无** | **无** | **不改** | **仅 GDS** |
| C4 | 投影交叉不连 | 几何宏 | 无 | 无 | 不改 | 仅 GDS |
| D | 线宽阶梯 | 几何宏 | 无 | 无 | 不改 | 仅 GDS |
| E | 配准标记 | 几何宏 | 无 | 无 | 不改 | 仅 GDS |

**判据（修正后）**：
> 若该结构的研究主张需要"这条金属属于哪个逻辑信号" → 必须有端口，
> 且**同一物理导体上的所有 PORT 必须属于同一个 PIN**。
> 若只需要几何位置 → 无端口，用 GDS 表达。

## 8. 为什么这次不会再循环

之前循环的根源是**没有先定义"物理—网表"的一致性契约**：

| 轮次 | 症状 | 只修了什么 | 漏了什么 |
|---|---|---|---|
| 1 | 路径错 | 移动文件 | 没问宏的电气语义 |
| 2 | 宏被删 | blackbox+keep | 没问实例存活后网表是否与物理一致 |
| 3（本可预期）| LVS/短路 | ？ | 若不解决 K1，仍会错 |

**本轮解决的是 K1（物理短路 vs 两 net）这个根本矛盾**：
- 用方案 α，网表里只有一个 net，与物理的"一条导体"一致
- 不再有"两个 net 被物理短接"的隐患

**同时建立了可执行的契约**：
- `p3_assert_pin_port_contract.py` 会持续检查"PIN 名 == 端口名"和"PORT 同分量"
- 任何未来的改动若破坏契约，会立即被断言拦下
