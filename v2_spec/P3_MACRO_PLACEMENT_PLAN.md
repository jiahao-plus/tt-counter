## 4. 与 PDN 的关系（未验证）

V1 实测 M4 电源条：宽度 1.600 µm，间距 27.14 µm，offset 13.57 µm，
x 位置 19.08 / 22.38 / 57.95 / 61.25 / 96.82 / 100.12 / 135.69 / 138.99 µm。

**2×2 的 PDN 布局未知**。若沿用 1×1 的 27.14 µm 间距外推，
则 2×2 会有约 12 组条。宏放在 y = 155–204 的顶部区域，
**必然与 M4 竖直电源条相交**。

这不一定违规——宏的 M1/M2/M3 几何在 M4 之下，M4 条在上方不构成短路，
但会**遮挡 SEM 成像**。

### 4.1 待验证项

| 项 | 状态 |
|---|---|
| 宏是否与 M4 strap 重叠 | **UNKNOWN**（无 2×2 PDN 数据）|
| M4 遮挡对 SEM 的影响 | 需在拿到真实 GDS 后评估 |
| 是否需要把宏移到 strap 之间的空档 | 视 CI 结果决定 |

### 4.2 备选方案（若遮挡严重）

若首次 CI 显示 M4 strap 覆盖了研究带：
1. 把宏移到 strap 间距的空档（需知道真实 strap x 位置）
2. 或用 `FP_PDN_*` 配置调整顶部区域的 PDN 密度（**需评估是否影响全局供电**）

**本轮不预设这些改动**，等真实数据。

    "gds": ["dir::../macros/out/struct_A.gds"],
    "lef": ["dir::../macros/out/struct_A.lef"]
  },
  ... (七宏各一条)
},
"IGNORE_DISCONNECTED_MODULES": [
  "research_fiducial", "u_rs_fiducial",
  "research_cross", "u_rs_cross",
  "research_dense", "u_rs_dense"
],

**只对 C4/D/E 三个非电气宏做 disconnect 豁免**。
A/B/C1/C3 四个电气宏全部有真实 PIN，不依赖此开关。

**未添加**：`RUN_LVS`、`RUN_PDN`、`ERROR_ON_PDN_VIOLATIONS` —— 保持默认开启。
