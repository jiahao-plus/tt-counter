# V2 需求矩阵（Requirements Matrix）

版本：v0.1（P1 初稿）
日期：2026-10-28
目标 Tile：**2×2**（335 × 226 µm 名义）
约束来源：用户已确认的 8 条设计决策（见任务书 §0）

> 分级：**MUST** = 硬性要求，做不到必须报告 FAIL；
>       **BEST_EFFORT** = 尽力实现，做不到记录 `NOT_SUPPORTED` 与客观原因。

## 1. 结构 A：M1–Via1–M2 信号连接（**MUST**）

| 项 | 内容 |
|---|---|
| **研究目的** | 提供"真实信号网络跨 M1/Via1/M2 三层"的 SEM 可成像样本，用于跨层连通重建 |
| **实现方式** | 自定义物理宏：M1 走线 → Via1 cut → M2 走线，全部属同一 Net |
| **目标层** | M1 (68/20)、Via1 (68/44)、M2 (69/20) |
| **是否电气连接** | ✅ **是**（必须真实连接，不是几何叠放） |
| **期望 Net 类别** | SIGNAL（非电源、非时钟） |
| **预期几何** | 每实例：≥1 个 Via1 cut（0.15×0.15 µm），M1/M2 landing 满足 enclosure |
| **预计面积** | 单实例 ≈ 8×5 µm（见 `macros/out/feasibility_via.gds`，实测 8.07×4.64 µm） |
| **所需接口** | 逻辑端口 A（M1）、B（M2），接入真实信号路径 |
| **DRC 风险** | 低——已用实测规则生成并通过本地几何 DRC（0 违规） |
| **真值可追溯** | ✅ GDS 几何 + DEF net 归属 + LEF PIN 三方一致 |
| **ROI 建议** | 每实例中心为 ROI 原点，10×10 µm 窗口 |
| **验收方法** | ① GDS 中 Via1 cut 存在且被 M1/M2 双向 enclosure<br>② DEF 中该 cut 属 SIGNAL net<br>③ 几何连通图：M1–Via1–M2 为单一连通分量 |
| **当前状态** | ✅ **可行性已验证**（`macros/out/feasibility_via_report.json`，自检 7/7 PASS；`geom_drc.py` 0 违规；负向对照 3/3 被抓） |

## 2. 结构 B：M2–Via2–M3 信号连接（**MUST**）

| 项 | 内容 |
|---|---|
| **研究目的** | 第二个跨层样本，层对更高（M2/M3），验证方法在多层可迁移 |
| **实现方式** | 同 A，但用 M2 → Via2 → M3 |
| **目标层** | M2 (69/20)、Via2 (69/44)、M3 (70/20) |
| **是否电气连接** | ✅ 是 |
| **期望 Net 类别** | SIGNAL |
| **预期几何** | Via2 cut 0.20×0.20 µm；M2 enclosure ≥0.040；M3 enclosure ≥0.065 |
| **预计面积** | ≈ 10×6 µm |
| **DRC 风险** | 中——M3 最小宽度 0.30（比 M1/M2 大 2 倍），走线更占面积 |
| **真值可追溯** | ✅ 同 A |
| **ROI 建议** | 每实例中心，10×10 µm |
| **验收方法** | 同 A，层对换成 M2/M3 |
| **当前状态** | ⏳ **未实现**。规则已提取，尚未生成实例。P2 首项 |

## 3. 结构 C：拓扑正负样本（**MUST**）

### C1 单 Net 分支（正样本）
| 项 | 内容 |
|---|---|
| 目的 | 单网络多分支，测试连通分量正确合并 |
| 实现 | 一个 Net 在 M1 上分叉成 ≥3 个端点，经 via 上到 M2 再分支 |
| 层 | M1 + Via1 + M2 |
| 电气 | ✅ 相连 |
| 验收 | 几何连通图该 Net 为**单一**分量，端点数 = 设计值 |

### C2 长连接（正样本）
| 项 | 内容 |
|---|---|
| 目的 | 长距离单网络，测试 SEM 大尺度拼接 |
| 实现 | 长度 ≥ 50 µm 的连续走线（含 ≥1 次层切换） |
| 验收 | 首尾端点在同一连通分量 |

### C3 合法的近邻不同 Net（负样本）
| 项 | 内容 |
|---|---|
| 目的 | 两条不同 Net 平行且极近，SEM 下可能粘连但电气不相连 |
| 实现 | 平行走线，间距取合法值：**0.14 / 0.20 / 0.28 / 0.50 µm** |
| 电气 | ❌ **不相连**（但都合法） |
| **严禁** | 制造真实短路或 DRC 违规来凑负样本 |
| 验收 | 两 Net 在连通图中是**不同**分量；DRC 0 违规 |

### C4 跨层投影交叉但不连接（负样本）
| 项 | 内容 |
|---|---|
| 目的 | M1 与 M2 平面投影重叠但无 Via1，SEM 投影下看似相交实为开路 |
| 实现 | M1 与 M2 图形在 XY 上交叉，交叉区**无任何 via cut** |
| 电气 | ❌ 不相连 |
| 验收 | 连通图中 M1 分量与 M2 分量**分离**；GDS 中交叉区 via1 计数 = 0 |

## 4. 结构 D：几何密度对照（**MUST**）

| 项 | 内容 |
|---|---|
| 研究目的 | 不同线宽/间距/方向组合，用于 SEM 计量与分割鲁棒性 |
| 实现方式 | 规则阵列（pitch ladder），每档多个周期 |
| 目标层 | M1、M2、M3 |
| 是否电气连接 | ⚠️ 可为 `NON_ELECTRICAL`（纯几何试片）或接入测试网络 |
| 合法取值（**实测规则**） | 线宽：M1/M2 = 0.14/0.20/0.30/0.50/1.00/3.00 µm<br>线宽：M3 = 0.30/0.50/1.00/3.00 µm<br>间距：0.14/0.20/0.28/0.50/1.00 µm |
| **严禁** | 使用虚构参数或低于 min 规则的取值 |
| 预计面积 | 3 层 × 6 档 × 5 µm = 约 90 µm² 起，可按需放大 |
| DRC 风险 | 中——3 µm 以上宽度触发 `huge_m1` 规则（间距需 0.28） |
| 真值可追溯 | ✅ 每档有明确 geometry manifest |
| 验收 | DRC 0 违规；每档线宽/间距在 GDS 中实测等于设计值 |

## 5. 结构 E：SEM 配准标记（**MUST**）

| 项 | 内容 |
|---|---|
| 研究目的 | 多层 SEM 图像的跨层对齐基准 |
| 实现方式 | 在 ≥2 个相邻金属层放**可识别、可重复**的几何图样（十字/方块阵列） |
| 目标层 | 至少 M1 + M2（最好再加 M3） |
| 是否电气连接 | ❌ `NON_ELECTRICAL`（纯几何，不赋 Net） |
| **严禁** | 虚构 Net 标签；用 met4 silicon-art 冒充 M1/M2 标记（V1 已证伪） |
| 关键风险 | ① 顶层 PDN/M4 遮挡<br>② dummy fill 覆盖<br>③ 密度规则可能拒绝孤立图样 |
| 预计面积 | 每个标记 ≈ 5×5 µm，建议 ≥4 个分布全 die |
| 验收 | ① GDS 中标记在 M1 与 M2 上**位置对齐**（同 x,y）<br>② 不被 M4/PDN 覆盖（几何相交检查）<br>③ 通过 DRC |

## 6. 结构 F：信号多 cut Via（**BEST_EFFORT**）

| 项 | 内容 |
|---|---|
| 研究目的 | 信号网络上的多 cut via（冗余 via），抗单 cut 失效 |
| **V1 结论** | V1 中信号多 cut = **0**，多 cut 仅用于电源（ROWCOL 1×4/1×5） |
| V2 可行性 | **UNKNOWN**——取决于 LibreLane/OpenROAD 是否为信号 net 生成多 cut |
| **判定方法** | 解析 V2 的 DEF `VIARULES`，统计每个 net 类的 ROWCOL |
| **必须区分** | 真实独立 cut 数 vs Via 实例数 |
| **分类要求** | signal / clock / power **分开**统计 |
| 若不可行 | 记录 `NOT_SUPPORTED` + 客观原因（工具行为/规则限制），**不以电源多 cut 替代** |
| 实现路径（若可行） | 自定义宏中手工放 2×1 或 2×2 cut 阵列，满足 via spacing 0.20 |
| 验收 | DEF 中该 net 的 via 实例 ROWCOL > 1，且 net 类型 = SIGNAL |

## 7. 结构 G：可电测 Via 链（**BEST_EFFORT**）

| 项 | 内容 |
|---|---|
| 研究目的 | 通过引脚测量 Via 链电阻/通断，提供电学真值 |
| 前提 | 引脚资源 + P&R 允许 + 测试代价可接受 |
| 实现方式 | 菊花链：pin_in → Via1 → Via2 → Via1 → ... → pin_out |
| 目标层 | M1/Via1/M2/Via2/M3 |
| 必须定义 | ① 预期输入/输出<br>② 测试向量<br>③ 物理真值（链上 via 数、预期电阻量级） |
| **禁止** | 未定义测试向量却声称"可电测" |
| 风险 | TT 的 uio 引脚数有限；可能挤占研究结构面积 |
| 当前状态 | ⏳ 评估中。若引脚不足则 `NOT_SUPPORTED` |
